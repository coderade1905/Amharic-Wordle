## ✍️ How to Write in Amharic  
Typing Amharic on a regular keyboard? We got you covered. Choose from multiple smart input methods:

### 1️⃣ Consonant + Vowel  
Example:  
`N + A` → `ና`

---

### 2️⃣ Consonant + Number  
Use numbers to select variations of a letter:  
- `N + 1` → `ነ`  
- `N + 2` → `ኑ`  
- `N + 3` → `ኒ`  
- `N + 4` → `ና`  
... and so on!

---

### 3️⃣ Consonant + Arrow Keys ⬆️⬇️  
Cycle through variants using arrow keys:  
- `ነ + ↑` → `ኑ`  
- `ኑ + ↑` → `ኒ`  
- `ኒ + ↓` → `ኑ`  
- `ኑ + ↓` → `ነ`

---

### 4️⃣ Switch Between Amharic Letters on Same Key 🔄  
Some English letters map to **multiple Amharic characters**. For example, `S` maps to `ሸ`, `ሰ`, `ሠ`.

👉 Use **Left ↔️ Right Arrow Keys** to toggle:  
- `S` → `ሸ`  
- `→` → `ሰ`  
- `→` → `ሠ`  
- `←` to go back

---

### 💡 Pro Tip:  
Try out each method and see which one feels natural for you. Practice makes perfect!
